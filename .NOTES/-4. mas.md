# MAS Engineering：多 Agent 系统的协作设计与实现

## 1、总览

Harness 支撑 Agent 的运行，MAS 进一步处理多个 Agent 之间的分工与交互。

多个 Agent 可以共同使用一套运行环境，也可以分别运行并通过通信协作。

增加执行主体并不自动提高任务质量，还会增加通信、协调和结果核验的成本。

是否采用 MAS，需要根据任务的可分解性、能力差异、并行收益和协作成本判断。
